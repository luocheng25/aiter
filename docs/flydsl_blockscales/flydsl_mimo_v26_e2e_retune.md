# MiMo V2.6：gfx942 decode 特化后的全量 E2E 再调优

日期：2026-10-13。完成 gfx942 编译期特化后，在当前 **MI350X/gfx950** 上重新
调优两份用户指定的 untuned 输入，M1～32768、2倍递增，各16行。

| 模型 | H | I per TP | Experts | TOPK |
|---|---:|---:|---:|---:|
| Pro-RL | 6144 | 256 | 385 | 9 |
| Flash-RL | 4096 | 256 | 257 | 9 |

输入为 BF16、FP8 E4M3FN blockscale weights、separated/unclamped SiLU。
随机 routing，没有强制第9路为 shared expert。本报告不是 gfx942 性能结果。

## 已写回的进一步提升

基线是**本轮开始时对应 tuned CSV 中的配置**：小 batch 仍是上一轮 native
搜索赢家，大 batch 已包含 blockscale prefill 赢家；不是未调优默认配置。
没有重复整个 native 搜索。基线和 E2E 候选均在本轮重新测量。

## 搜索、精度与计时口径

1. 实际使用原 `FmoeTuner.e2e_tune`，每模型340项：320个原 prefill
   shape/config 组合，加20个适用的小 batch decode 组合。
   Pro332项通过、8项失败，均是 M32768 的 M128 independent/persistent×OC1/2/4/8；
   对应已有 packed buffer 容量限制，未放宽边界。Flash340项全部通过。
2. E2E 原始输出 Pro更新6行、Flash更新7行；独立验证后按上节规则各发布5行。
   所有搜索失败及未采用赢家保留在原始记录，不删除失败样本。
3. reference、容差不变：两次 A1x128 activation quant 的 Torch reference；
   有限/非零输出且 `err_ratio <= 0.1` **或** `logits_diff <= 0.01`。
   新 `block_a16w8` 是明确的 weight-only 路径，不能视为 A8W8 等价实现。
4. 新 decode 的计时输出相对 A8W8 reference：Pro err_ratio约77.4%～78.2%，
   logits_diff约0.000982～0.001052；Flash err_ratio约71.4%～72.9%，
   logits_diff约0.000930～0.000960。它们通过原有 logits_diff 条件，
   **不通过逐元素 err_ratio 条件**。相消反例也证明两种数值流程不等价。
   四个更新 prefill 的 logits_diff约0.0000042～0.0000044。
5. 独立 ABBA 共32个 shape×4轮=128轮；每轮都核对真实 CSV dispatch、
   warmup 输出和计时输出。沿用 Aiter `run_perftest`：5 warmups、101 iterations、
   2组轮换参数、原首轮剔除/IQR 聚合，每实现两个返回值取中位数。
   同 shape 共用逻辑输入，轮换 allocation 每轮重新 deepcopy，不保证同址。
6. 完整 MoE **GPU kernel 时间之和**，包括对应路径的 sort/量化/Gate/Down/
   clear/counter/reduce；不含权重准备/shuffle、topk生成、JIT、CPU提交间隙或TP通信。
   有效 FLOPs：$F=6M\times TOPK\times H\times I$，
   $TFLOPS=F/(t_{us}\times10^6)$。

环境：MI350X gfx950、256CUs、HIP logical0 / PCI0000:75:00.0；
FlyDSL0.3.4.1、Python3.10.12、Torch2.9.1+rocm7.2.0.git7e1940d4、
HIP7.2.26015-fc0010cf6a。未改频率/功率/PTL，没有 PTL 认证或锁频保证。

## 代码与发布验证

- [gfx942 特化说明](flydsl_mimo_v26_decode.md#gfx942-编译期特化同日追加)：
  24个 gfx942 Gate/Down 特化离线编译通过、无 gfx950-only 指令；
  12个 gfx950 模型特化 ELF 与改动前完全相同。
- 当前 gfx950 定向回归169项通过、1项预期skip、570个子测试通过。
- 最终 CSV 的默认 config family 合并检查20项通过；新进程对两模型全部
  **32行 public dispatch/output buffer 验证通过**，禁止 PyHIP 导入。
- 磁盘核对每模型只改5行，更新行与原始 E2E 输出一致，未更新行逐字节保留；
  没有改变主 dispatcher、kernel 数值门槛或用户暂存版本。
- **gfx942 的硬件正确性和性能尚未测试**，由用户在 gfx942 机器运行同一
  [decode pytest](../op_tests/flydsl_tests/test_blockscale_decode.py)。
  该平台应使用 FNUZ 输入并重新调优，不能把本次 gfx950 tuned CSV 当作 gfx942 结果。
